## 二、⚠️ 偏离基线(需在 README/ADR 明示,并按需修)

| # | 基线条款 | 现状 | 建议 |
|---|---|---|---|
| D1 | 配置 **TOML 唯一格式**;未知键报错 | Go/Python 侧均为 **JSON** 配置;JSON 解析未开启未知键报错 | 迁 TOML(BurntSushi/toml,`DisallowUnknownFields` 等价:`md.Undecoded()` 报错)或写偏离说明(ADR) |
| D2 | 应用包含 `/healthz` `/readyz` `/version`(ldflags 注入) | **均缺失** | 增加三端点;Makefile 注入 `-X main.version/commit/buildTime` |
| D3 | 优雅退出:SIGTERM 停止接收→在途 drain→后台取消 | 仅 `srv.ListenAndServe()`,无 Shutdown | `signal.NotifyContext` + `Shutdown(20s)`;poller 同 ctx |
| D4 | IO 可取消:外部调用用请求 context 派生 | `agentCall` 用 `http.NewRequest`(**未带 ctx**),仅固定 90s 超时 | 传 `r.Context()` 派生 + 超时 |
| D5 | 依赖纯度:CI 校验 `CGO_ENABLED=0` | 代码纯 Go ✅,但 **无 make check-cgo / CI 门禁**(vet/staticcheck/race/govulncheck 均未接入) | Makefile/CI 增门禁目标 |
| D6 | 迁移文件纳入版本控制,只前进;禁手工改线上表 | 仅 `schema.sql`(内嵌 IF NOT EXISTS/ALTER),**无 migrations/ + schema_migrations** | 目录化 `migrations/000N_*.sql` + 版本表;首次以基线快照落地 |
| D7 | i18n:后端返回 **code+参数**,前端渲染文案 | 有错误 `code`,但 `message` 为**中文句子**;前端靠 DOM 词典翻译(临时方案) | 后端增 `message_key`+`params`(保留 message 兼容),前端逐步换 vue-i18n keys |
| D8 | 主题 light/dark/**auto** | 仅 light/dark 手动切换;首屏防闪烁已做 ✅ | 增 auto(跟随 `prefers-color-scheme`) |
| D9 | 安全加固:登录失败限速/锁定;安全响应头;CSP | 均无(响应头可随 R1 在 Caddy 层加) | Caddy 统一加 HSTS/XCTO/XFO/CSP;登录加限速与锁定 |
| D10 | 可观测性:slog JSON + request_id;Prometheus 指标 | 无结构化日志/指标;审计表已有 | 中期项:middleware(slog+request_id)、/metrics |
| D11 | 压缩缺省 zstd | 平台自身 HTTP 未启用压缩(数据面压缩由 ZFS 层承担;前端 gzip 打包) | 随 R1 在 Caddy `encode zstd gzip`,并写偏离/说明 |
| D12 | Agent 语言=Go 单二进制 | Agent 为 **Python**(rtslib 生态) | 已有合理性说明;建议补 `docs/adr/0002-agent-python.md` 正式记录 |

## 三、✅ 已符合(抽样)

Go 单二进制 + 前端 `embed.FS`(前端打进服务端)✔;`pgx/v5` 连接池 + PostgreSQL 17 ✔;
RBAC(admin/operator/viewer)+ 全业务接口认证 ✔;口令 bcrypt、CHAP 密文 AES-256-GCM 存 DB ✔;
审计 append-only 表(谁/何时/动作/参数脱敏/结果/耗时)✔;请求体 `MaxBytesReader` + `DisallowUnknownFields` ✔;
SQL 全参数化、无字符串拼接、limit 白名单 ✔;无 `InsecureSkipVerify`、无 cgo 依赖 ✔;
会话令牌有效期 7 天 ✔;Agent 仅回环监听 ✔;破坏性操作二次确认 ✔。
